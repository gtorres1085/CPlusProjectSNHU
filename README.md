\### 4. BlackJackCore – Full Blackjack Game Engine

\*\*Folder:\*\* `BlackJackCore`  



A complete, console-based blackjack game that follows realistic American casino rules.



\*\*Features:\*\*

\- 6- or 8-deck shoe

\- Dealer hits soft 17

\- American hole-card rules (dealer peeks for blackjack)

\- Blackjack pays 3:2

\- Double down on any hard total 2–11

\- Split all pairs (10-value cards treated the same), aces split once

\- Insurance when dealer shows an Ace (up to half the bet, pays 2:1)

\- Automatic reshuffle when 75% of the shoe has been used

\- Table limits:

&nbsp; - Minimum bet: \\$5

&nbsp; - Maximum bet: \\$3000

&nbsp; - Maximum buy-in: \\$10,000

\- Player name input

\- Basic session stats (hands played, wins/losses, etc.)



\*\*Skills demonstrated:\*\*

\- Advanced C++ control flow and state management

\- Game loop architecture

\- Randomization and card shuffling

\- Encapsulating game rules and payouts

\- Clean console UI for a multi-step game



\*\*Main file:\*\*

\- `main.cpp`
